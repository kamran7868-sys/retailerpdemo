# NexaRetail ERP Dashboard

A frontend-only retail management and ERP dashboard built with React, Vite, Recharts, and Lucide icons.

## Available scripts

- `npm run dev` starts the local development preview.
- `npm run build` creates the production bundle in `dist`.
- `npm run lint` runs the source checks.

The current scope is the dashboard UI only. All business data and interactions are demo-only and designed to be connected to future multi-tenant ERP services.
